Dataset Splitting & Zero Data Leakage Architecture
70 : 15 : 15 Stratified Split

To prevent Empirical Overfitting and ensure strict generalization standards, all 100,000 accident records are partitioned into three isolated sets using target stratification:

1. Training Set 70% (70,000 Rows)

Fit Parameters: Computes model weights, biases, and tree splits. Feature transformers (StandardScaler, Imputer) compute statistics (μ, σ) exclusively from this set.

2. Validation Set 15% (15,000 Rows)

Tune Hyperparameters: Evaluates candidate tree depths (max_depth), regularization penalty (C, α), and ensemble sizes to select the champion architecture before deployment.

3. Vault-Locked Test Set 15% (15,000 Rows)

Unbiased Generalization: Evaluated strictly ONCE after all decisions are finalized. Never seen during training or tuning, guaranteeing zero evaluation or lookahead leakage.

Zero Data Leakage Protocol: Preprocessing transformers are fitted using scaler.fit_transform(X_train), while validation and test sets strictly receive scaler.transform(X_val) and scaler.transform(X_test) to prevent validation statistics from contaminating model weights.

EDA-Guided Feature Screening (Why Columns Were Dropped)

During Exploratory Data Analysis (EDA), we identified features with high missingness, zero variance, post-event leakage, and redundancy:

Dropped Columns Reason from EDA Simple Justification
End_Lat, End_Lng 100% Missing No data present in any record; completely empty.
Wind_Chill(F), Precipitation(in) >92% Missing Severe missing values; temperature and humidity already capture atmospheric conditions.
Start_Time, End_Time Timestamp Strings / Leakage String timestamps (YYYY-MM-DD HH:MM:SS); not usable as raw numbers, and End_Time introduces post-accident leakage.
Country, Turning_Loop Zero Variance Every row is identical (all 'US' or all False); gives 0 predictive information.
ID, Description, Street, Zipcode Unstructured / IDs Arbitrary database keys and long text; continuous GPS coordinates are used instead.
Weather_Timestamp, Airport_Code Redundant Metadata Duplicate station metadata; direct weather sensor readings are used directly.
